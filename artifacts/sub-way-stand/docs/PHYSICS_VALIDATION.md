# 물리 모델 검증 및 심사 대응 — 2026-10-14

계산식, 방향 판정, 불확실성 표시를 보강했고 재현 가능한 해석적 검증을 수행했다. **실제 서울 지하철에서의 예측 정확도와 낙상 예방 효과는 아직 측정하지 않았다.** 아래 수치 오차는 같은 물리 가정에서의 구현 오차이며 현장 오차가 아니다.

## 모델과 변경 근거

이 엔진은 선로면의 준정적 횡방향 가속도를 계산한다. 인체의 자세, 반응 지연, 발 위치, 손잡이 사용이나 차체 현가장치까지 예측하는 인체 동역학 모델은 아니다. 화면의 기울기 애니메이션도 실제 신체 각도를 측정한 값이 아니다.

진행 방향을 바라보는 좌표계에서 κ > 0은 좌곡선, θ > 0은 좌측으로 기운 선로다. R은 수평 곡선 반경(m), v는 속도(m/s), θ는 캔트 각(rad), g = 9.80665 m/s²다.

```text
a_y = v² κ cosθ − g sinθ
κ = ±1/R
```

`a_y > 0`이면 준정적 관성 쏠림은 오른쪽, `< 0`이면 왼쪽이다. 이것은 사람이 반드시 그 방향으로 이동한다는 예측이 아니다. 선로면 투영의 `cosθ`를 반영했다. 평형 조건 `tanθ = v²κ/g`에서 결과가 0이 되는지도 검증했다. 이 좌표 변환은 철도 준정적 곡선 모델에 근거한다. [Persson, 2008, KTH 학위논문](https://kth.diva-portal.org/smash/get/diva2:13865/FULLTEXT01.pdf)

공간에 따른 곡률·캔트 변화와 가감속이 있을 때는 직접 미분한 식을 사용한다.

```text
j_y = (2v a_long κ + v³ dκ/ds) cosθ
      − (v²κ sinθ + g cosθ) v dθ/ds
```

기존 `v³ dκ/ds` 함수는 **등속·평탄 선로**의 특수 경우로 유지된다. `syntheticFrame`은 실제로 사용 중인 정현파 속도의 `dv/dt`까지 반영한다. 앱의 실제 노선 예측은 횡가속도·방향·ETA를 출력하며, 노선에 없는 캔트 전이 자료를 만들어 저크 수치로 보여주지는 않는다.

## 잘못된 안내를 막는 조건

| 문제 | 수정된 동작 |
|---|---|
| 최고 속도에서는 바깥쪽, 진입 저속에서는 안쪽으로 쏠릴 수 있음 | 곡선 진입부터 이탈까지 최소·최대 속도를 모두 사용. 방향이 바뀌거나 판정 경계에 걸리면 보류 |
| 실시간 캔트 자료 없음 | 캔트 미상을 0으로 단정하지 않고 `low-confidence`로 보류 |
| 시뮬레이션 캔트 자료 없음 | 0을 가정하되 설명에 `캔트 미상·0 가정` 표시 |
| 역 좌표 근사·OSM 중심선이 실측 선로로 오해됨 | 기존 `curated` 선로·곡선 검증 조건을 유지. OSM 경로도 현재 미검증 자료이며 실시간 방향 안내는 보류 |
| 반올림으로 계산 범위가 줄어듦 | ETA·위치·가속도 하한은 내림, 상한은 올림. 원래 계산 범위 포함 |
| ETA의 가장 빠른 진입만 0에 도달함 | 실시간 음성은 `곡선 진입 가능 구간입니다`로 표현. 가장 늦은 진입도 임박한 경우의 문구와 구분 |
| 0.15 m/s²가 의학적·인체 체감 기준으로 오해됨 | 앱의 **안내 표시 기준**이라고 명시. 낙상·안전·인체 체감 임계값 주장 제거 |
| 수치 오버플로 또는 잘못된 입력 | 명시적 오류 또는 보류. 무한대·NaN을 방향·강도로 출력하지 않음 |

속도·정차·보고 지연 범위는 현재 모델 가정이다. ETA와 가속도 범위는 해당 가정 안에서의 범위이며 모든 실제 운행을 포함한다고 보장하지 않는다. `high/medium/low`도 경험적으로 보정한 확률이나 95% 신뢰구간이 아니다.

## 현장 정확도를 검증하려면 필요한 측정

실제 정확도는 다음 자료가 확보된 뒤 평가해야 한다. 이 작업에서는 자료를 임의 생성하거나 실측으로 표시하지 않았다.

1. 실제 운행 선로의 반경·캔트·전이 길이와 측정 불확실성 확보.
2. 고정 장착·축 정렬한 보정 IMU와 동기화된 속도·위치 기준값 기록. 휴대폰은 기종·위치·샘플링률을 기록하고 중력·좌표계를 맞춤.
3. 가속·등속·제동 및 양방향 운행을 수집. 불규칙 정차도 포함. 경로·날짜·기기별로 개발 데이터와 독립 평가 데이터를 분리.
4. 동일 좌표계·대역폭에서 MAE/RMSE, 방향 오안내율, 진입 시간 오차, 안내 보류율, 범위 포함률을 함께 공개. 센서 관측 시각·안내 시각·실제 곡선 진입 시각을 동기화.
5. 안내 효과나 낙상 예방 효과는 가속도 일치도와 별개의 사용자 연구로 평가.

## 재현 명령

저장소 루트에서 실행한다. 추가 패키지는 필요 없다.

```powershell
pnpm --filter @workspace/sub-way-stand test
pnpm run typecheck
pnpm --filter @workspace/sub-way-stand exec node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/validate-physics.mts
pnpm run build:web
```

검증 스크립트는 오차·회귀 조건이 기준을 벗어나면 실패하며, 성공하면 원시 JSON을 다시 생성한다. 단위·통합 테스트에는 기존 센서·안내·데이터 출처 검증과 새 물리 회귀 테스트가 포함된다.
